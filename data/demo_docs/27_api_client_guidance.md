# AtlasDesk v2 调用方重试与分页实践

## 调用准备
本文为虚构演示资料，适用于使用客户端凭据访问 AtlasDesk v2 的服务。调用方先获取具备相应权限的访问令牌，按实际到期时间更新。客户端凭据流程不签发刷新令牌，不能照搬交互式登录的刷新逻辑；客户端密码与访问令牌都不能写入业务日志。

## 重试分类
网络失败时，创建工单请求应复用原幂等键和相同请求体。相同租户下，二十四小时内相同键与不同请求体会产生冲突，不能靠更换键掩盖一次不确定是否成功的请求。遇到限流时遵循 Retry-After 并加入随机抖动；认证、权限和参数错误应先修正原因，不进行无条件立即重试。

## 分页处理
列表使用服务端返回的 next_cursor 继续查询，默认每页二十条，最多一百条。游标按不透明值处理，不自行从工单编号拼接。遍历过程中可能存在新增或修改，因此需要处理重复结果并记录查询边界；不能仅凭两页返回数量推算整个知识库或业务工单总数。

## 结果核对
创建响应与通知到达是不同阶段，不能用收到一次回调证明创建只发生一次。调用方保留请求关联号、幂等键的安全摘要和业务结果，发生不确定失败时先查询现有工单再决策。Webhook 消费者仍按事件编号去重，遵循独立的接收协议。
