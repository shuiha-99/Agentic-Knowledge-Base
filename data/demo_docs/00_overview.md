# AtlasDesk 星河工单：知识库说明

## 资料范围
本知识库描述虚构的企业内部工单服务 AtlasDesk（星河工单），仅用于项目演示与评测。文档中的域名、人员、配置和数据均为演示内容，不代表真实企业运行结果。
产品负责人为研发平台组，业务对象是企业内部支持工单。系统包含 Python API、异步通知 Worker、PostgreSQL 数据库和 Redis 缓存。API 与 Worker 分开部署。

## 版本边界
v1 是单实例旧版，配置文件为 app.ini，监听端口为 8080。v2 是支持多副本的新版本，使用环境变量配置，默认监听端口为 8088。除非明确说明，新版文档中的 v2 配置不能直接套用到 v1。
关于升级步骤，请联合阅读部署、迁移、回滚文档；关于 API 权限，请联合阅读 API 与认证文档。资料未提供预算、员工薪酬、未发布版本路线图，系统应明确说明没有相关依据。

## 资料优先级
涉及特定版本时，以该版本的部署指南为准；迁移时以迁移清单为准。出现同一版本互相冲突的资料，应同时展示出处并提示人工确认，不能自行编造结论。
