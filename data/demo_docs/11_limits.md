# AtlasDesk v2 配额与附件

## 请求配额
每个租户的 API 请求限额为每分钟600次，突发容量100次。超过限额返回429，并带 `Retry-After` 秒数。客户端应等待指定时间并加入随机抖动，不能无限立即重试。
鉴权失败、参数错误不适合盲目重试；先修正令牌、权限或字段。网络失败时创建请求应复用原幂等键。

## 附件
v2 单个附件最大25 MiB，v1 最大10 MiB。允许的类型是 PDF、TXT、PNG 和 JPEG；文件名不能作为内容类型校验的唯一依据。附件下载必须检查租户权限。

## 通知约定
回调请求携带 event_id、ticket_id 与事件类型。消费者返回2xx表示已接收，重复 event_id 应返回既有处理结果。处理耗时较长时先持久化事件再异步处理，避免发送方因等待超时反复投递。
