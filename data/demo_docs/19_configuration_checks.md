# AtlasDesk v2 配置上线检查

**配置来源**
本文为虚构的 AtlasDesk v2 演示检查表。新版使用环境变量，旧版使用 app.ini，两套配置不能混用。检查时先记录程序版本和环境名称，再核对数据库、缓存、监听端口及签名配置；不能因为某个同名文件存在就认为程序已经读取其中的内容。

**必查字段**
核对 ATLAS_DATABASE_URL 指向 PostgreSQL 十五，ATLAS_REDIS_URL 指向 Redis 七。新版默认监听八零八八端口；签名密钥从受控配置注入，不得复制进诊断日志。数据库连接池按每个 API 副本分别计算，默认池大小十、溢出五，不能把它误认成所有副本共享的十五个连接。

**生效验证**
在不暴露密码和密钥的前提下，输出脱敏后的目标环境与配置摘要。启动后检查存活探针，再检查数据库和 Redis 都通过的就绪探针，最后执行创建、查询和权限冒烟。探针正常只能证明对应依赖检查通过，不能代替客户端权限、附件访问和外部通知的完整验证。

**失败处理**
出现连接失败时先确认环境、地址、网络与认证，不把新版 Redis 当成可选缓存绕开。发现错误环境配置立即停止接入流量，保留关联号和脱敏证据。升级时按《迁移清单》逐项核对旧配置映射；涉及客户端凭据时重新签发，不复用旧版会话签名密钥。
